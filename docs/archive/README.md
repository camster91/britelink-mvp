names. Notably, `SUPABASE_PROVISIONING.md` and `STAGING-PROVISIONING-RUNBOOK-2026-09-21.md`
describe *hosted* Supabase projects. The decision changed: production runs a self-hosted
Supabase stack on the VPS (`supabase/selfhosted/`).
